# 도원이의 운동일지

휴대폰 홈 화면에 설치해서 쓰는 헬스 루틴·식단 관리 앱(PWA)입니다.

- 운동 루틴(가슴 / 등 / 어깨+하체, 프로그램 A·B·C 자동 교체), 세트별 무게·횟수 기록과 세트별 최고 기록
- 식단·단백질·칼로리 목표, 주간 체중 추세에 따른 칼로리 보정
- **오프라인 동작**: 한 번 열어두면 인터넷 없이도 실행됩니다. 기록은 휴대폰에 저장됩니다.
- **사진 영양 자동 계산(무료)**: 설정에 무료 Google Gemini API 키를 넣으면, 음식 사진을 찍는 즉시 탄수화물·단백질·지방이 계산됩니다. 키 발급: https://aistudio.google.com/apikey (카드 등록 없음)

## 휴대폰에 설치하기

배포 주소(GitHub Pages)를 휴대폰 브라우저로 엽니다.

- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
2. `main` 브랜치에 푸시하면 `.github/workflows/pages.yml` 이 자동 배포
3. 주소: `https://<사용자명>.github.io/<저장소명>/`

> 비공개(private) 저장소의 Pages는 GitHub 유료 플랜(Pro 등)이 필요합니다. 무료 계정이면 저장소를 공개로 바꾸거나 Netlify·Cloudflare Pages 같은 무료 정적 호스팅에 이 폴더를 올리면 됩니다. 기록과 API 키는 각자 휴대폰에만 저장되므로 코드를 공개해도 개인 데이터는 노출되지 않습니다.

## 데이터

- 모든 기록은 기기(브라우저 저장소)에 저장됩니다. 휴대폰 교체 전에 **설정 → 백업 파일 저장**으로 백업하고, 새 기기에서 **백업 불러오기**로 복원하세요.
- Gemini API 키는 기기에만 저장되며 백업 파일에 포함되지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면·로직) |
| `manifest.webmanifest` | 홈 화면 설치 정보 (이름·아이콘·색) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icons/` | 앱 아이콘 |
